# Uso de Inteligência Artificial — AgroAlert

Durante o desenvolvimento do AgroAlert, utilizamos o ChatGPT como ferramenta de apoio para relembrar conceitos de lógica de programação em Python, esclarecer dúvidas e revisar o código.

# Exemplos de prompts utilizados

- Como utilizar listas em Python para armazenar os dados de várias plantações?
- Como utilizar estruturas de repetição para manter um menu funcionando?
- Como validar se um percentual de umidade está entre 0 e 100?
- Como melhorar a organização e a apresentação das informações no terminal?

As respostas foram utilizadas como apoio ao aprendizado e à revisão do código, respeitando os conteúdos estudados em aula.

A ferramenta auxiliou na revisão da lógica de cadastro de plantações, consulta de dados, classificação da umidade e orientações de irrigação.

O uso da IA facilitou a compreensão dos conceitos, mas as sugestões precisaram ser analisadas e testadas para verificar se estavam adequadas aos conteúdos estudados em aula e ao funcionamento do projeto.
